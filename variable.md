# JavaScript Learning

What is js?

   JavaScript is a programming language mainly used to make websites interactive and dynamic typed language.
   
Firstly Types of Programming Languages

1. OOPS
2. Procedural language
3. Scripting language

In JS will support for OOPS and scripting language.

It have two typed languages are there:

1. Static
2. Dynamic

Static means values based datatype are only accepted.

But dynamic means values based we have to change keywords.

In JS 3 types of keyword are there:

1. `let`
2. `var`
3. `const`

In `var` accepted all three method:

1. Variable declaration + initialization
2. Variable reinitialization
3. Variable redeclaration + initialization

But `let` are not accept this 3 methods. Only accept:

1. Variable declaration + initialization
2. Variable reinitialization

And `const` are not accepted this 2 method:

1. Variable reinitialization
2. Variable redeclaration + initialization
