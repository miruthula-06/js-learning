What is JS?

difference chrome v8 engine vs node.js
chrome v8 engine - Runs JavaScript in the browser
node.js - Runs JavaScript outside the browser

What is node.js?
It is runtime environment that allows us to run JavaScript outside the browser
Node.js uses the V8 engine to execute JavaScript.

Chrome:
JavaScript → Chrome → V8 → Execute JavaScript

Node.js:
JavaScript → Node.js → V8 → Execute JavaScript
